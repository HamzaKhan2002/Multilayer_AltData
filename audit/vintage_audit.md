# Vintage audit: first release vs latest vintage (thousand barrels)

First release = value printed for the current week in csv/table4.csv of the release that first covers that week (795 releases, week ending 2011-07-22 to 2026-10-16). Table 4 prints million barrels with three decimals, so values are exact to 1 kbbl. Latest vintage = cached EIA history files `W_EPC0_SAX_YCUOK_MBBLw.xls` (Cushing) and `WCESTUS1w.xls` (US commercial crude, excluding SPR), loaded with `altdata.eia.load`; gasoline and distillate have no cached latest series, so only the release-to-release check applies. Release-to-release check = `prior` value printed in release t+1 minus the first-release value of release t. Threshold: |difference| > 0.5 kbbl. Full table: `audit/vintage_audit.csv`.
